# Spilink

An independent solo practice space for all-spin combos, plonking, and B2B surges.

**Status: early preview under development.** Gameplay and replay compatibility are still being tested.

Sessions finish after the 400th piece by default. An optional **Continue after 400 pieces** setting lets you keep playing while keeping the first-400-piece result separate.

Spilink is not an official TETR.IO mode or achievement service.
